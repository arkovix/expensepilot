# ExpesePilot
ExpensePilot is a simple and user-friendly expense tracking web application that helps users to manage their daily expenses and controll extra expenses through catagorized monthly budget system

## Features
> User registration and login
> Add, Edit and Delete expenses
> Track daily expenses with charts
> Catagorized spending with budget
> Expense overview dashboard
> Responsive design for Mobile

## Tech stack
> Frontend: HTML, CSS, JAVASCRIPT
> Backend: PHP
> Database: MySQL

## Installation

1. Clone the repository
3. Create MySQL database named 'expensepilot'
4. Import SQL file
5. Create a file named db.php and add copy db.example.php to db.php
6. Run the project on a PHP supported server

## Security Note

The actual db.php file is excluded from the repository for security reasons. Use db.example.php as a template.

## Project Structure
> index.php : Main page
> dashboard.php : User dashboard and expense adding page
> budget.php : Catagory wise monthly budget showing page
> transaction.php : All transaction showing page
> accoutn.php : User account management page
> db.example.php : Example database configuration
> asset/ : All images contain
